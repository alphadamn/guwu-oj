为什么自己做一套 OJ

刷题网站很多，真正完整走一遍「需求 → 部署 → 判题 → 修 bug」的机会很少。 谷物 OJ 是我们在课程与兴趣驱动下搭起来的练兵场：要懂算法，更要懂系统怎么活着。

  • 同龄人视角 题面、反馈与手册按学生真实学习路径来写，而不是照搬成人竞赛站的语气。
  • 真系统，真判题 Django + 沙箱评测 + 队列，提交后能看到逐点结果，工程链路看得见。
  • 公开共建 代码在 GitHub 开源，课堂里改、线上跑，错误与进步都留在仓库里。
